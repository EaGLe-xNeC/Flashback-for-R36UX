# Flashback for R36UX — GitHub Presentation

## Repository Description

Enhanced Flashback experience for R36 Ultra X — fullscreen cinematics, restored audio cues, Sega CD voices and PortMaster support.

## About

Flashback for R36UX is an enhanced adaptation of
Gregory Montoir's REminiscence 0.5.6 engine.

It is designed specifically for the R36 Ultra X,
featuring a 4.5-inch, 1024x768 display.

## Highlights

- Enlarged fullscreen polygon cinematics
- Improved special cinematic animations
- Restored musical cues for selected sequences
- Sega CD voice support
- FN button exit support
- PortMaster integration
- Dedicated save directory
- ARM64 executable

## Tested Environment

Device: R36 Ultra X
Firmware: ArkOS4Clone
Display: 1024x768 (4:3)
